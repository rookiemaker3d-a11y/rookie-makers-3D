Módulo 1 — Web Pública (Landing)

Tu vitrina digital. Genera credibilidad, captura leads y filtra curiosos antes de que entren al ERP.

Explicación de ventas

El cliente potencial llega a www.rookiemakers3d.com y encuentra una experiencia inmersiva:

  • Hero impactante: "Hacemos Real lo que Imaginas" con CTA directo a cotizar o ver proyectos.
  • Servicios técnicos: FDM, SLA, prototipado industrial y figuras custom. Cada tarjeta genera confianza.
  • Smart Quote Calculator: El visitante sube su STL, elige material y obtiene estimado en segundos. Reduce llamadas de cotización innecesarias.
  • Galería de proyectos reales: Funkos, prototipos, piezas mecánicas. Demuestra calidad y versatilidad.
  • Testimonios (Comunidad Maker): Reviews con estrellas que aumentan conversión.
  • Responsive + modo claro/oscuro: Se ve perfecto en móvil y desktop.

Beneficio comercial: Filtra curiosos de compradores serios. El que llega al ERP ya está calificado.

Módulo 2 — Dashboard Principal

Vista de 360° del negocio al entrar. Datos, no opiniones.

Explicación de ventas

Cada usuario ve un resumen adaptado a su rol desde el primer segundo:

  • Admin: Ventas del mes, margen bruto, pedidos pendientes, alertas de stock bajo.
  • Vendedor: Cotizaciones recientes, productos propios vendidos, comisiones estimadas.
  • Diseñador: Archivos entregados, pagos pendientes por diseño.

Beneficio comercial: Toma de decisiones en segundos. Identifica qué vendedor performa y qué productos dejan más ganancia sin abrir Excel.

Módulo 3 — Cotizador Inteligente (6 pasos)

El corazón del ERP. De 30 minutos a 5 minutos por cotización. Sin errores de cálculo.

Explicación de ventas

Proceso paso a paso que cualquier vendedor domina en su primer día:

  • Paso 1 (Cliente): Selecciona cliente existente o crea uno nuevo. El sistema ya conoce su historial.
  • Paso 2 (Proyecto): Elige categoría: Prototipo funcional, Maqueta, Refacción, Decorativo, Gaming/Setup, Funko u Otro. Esto clasifica el trabajo para análisis posterior.
  • Paso 3 (Costos): Selecciona material (ej. PLA $400/kg), gramos estimados, horas máquina en formato HH:MM, costo de diseño y extras. El sistema calcula automáticamente el costo de producción.
  • Paso 4 (Resumen con margen): Slider para ajustar % de ganancia deseada. En tiempo real ves: precio cliente, ganancia neta, anticipo (50%).
  • Paso 5 (Vista previa): Tabla profesional con productos, materiales, cantidades, costos y totales. El cliente no ve costos internos.
  • Paso 6 (PDF + WhatsApp): Genera PDF con folio único, datos del vendedor y cliente. Comparte directo por WhatsApp o descarga.

Beneficio comercial: Reduce tiempo de cotización 6x. Elimina errores de cálculo. Da imagen profesional al cliente con PDF con folio.

Módulo 4 — Cotizaciones en Espera

No pierdas ninguna oportunidad de venta. Guarda, gestiona y convierte cuando el cliente esté listo.

Explicación de ventas

El cliente dice "déjame pensarlo". Antes se perdía la cotización en el chat. Ahora:

  • Guarda con un clic: La cotización queda en estado "En espera" con todos los datos intactos.
  • Autorizar venta: Cuando confirma, convierte en producto del catálogo.
    • General: Visible para todo el equipo (venta recurrente).
    • Propio: Visible solo para el vendedor creador (exclusividad comercial).
  • Historial completo: Fecha, cliente, vendedor, estado y total. Filtros por rango de fechas.

Beneficio comercial: Recupera ventas que antes se perdían por desorganización. Construye catálogo reutilizable sin esfuerzo.

Módulo 5 — Catálogo de Productos

Repositorio inteligente de todo lo que puedes vender, organizado por visibilidad.

Explicación de ventas

Cuando una cotización se autoriza, el producto entra al catálogo y alimenta automáticamente Análisis:

  • Generales: Piezas estándar que cualquier vendedor puede vender (ej: soportes, llaveros). Agiliza repetición de pedidos.
  • Propios: Diseños exclusivos de un vendedor. Protege la cartera comercial de cada persona.
  • Expandible: Cada producto muestra material, gramos, horas impresión, costo producción, costo final, ganancia neta y margen %.
  • Importar venta: Registra ventas manuales de productos existentes sin pasar por el cotizador.

Beneficio comercial: Construye catálogo reutilizable que reduce cotizar desde cero cada vez. Fomenta competencia sana entre vendedores.

Módulo 6 — Inventario

Control total de materiales de impresión y consumibles complementarios.

Explicación de ventas

Evita quedarte sin filamento a mitad de un pedido urgente. Dos niveles de control:

  • Filamentos: Registro por color, marca, tipo (PLA, PETG, ABS) y gramos disponibles. El cotizador consulta este stock en tiempo real.
  • Items / Consumibles: Todo lo que no es filamento pero sí cuesta dinero: cajas, tornillos, inserts, tiras LED, pinturas. Cada item lleva foto, costo unitario, cantidad y unidad de medida.
  • Asignación a cotización: Al cotizar, el vendedor asocia items del inventario. Próximamente: descuento automático de stock al autorizar venta.

Beneficio comercial: Elimina pérdidas por "se me acabó el material". Calcula el verdadero costo de cada trabajo incluyendo consumibles que antes se ignoraban.

Módulo 7 — Clientes y Diseñadores

Cartera de contactos organizada y base de colaboradores.

Explicación de ventas

No más buscar el teléfono del cliente en WhatsApp:

  • Ficha de cliente: Nombre, teléfono, email, empresa y historial completo de cotizaciones anteriores.
  • Recompra: Al ver el historial, el vendedor puede ofrecer "¿quiere el mismo pedido que hizo hace 3 meses?".
  • Diseñadores externos: Registro de freelancers o colaboradores con tarifa por archivo. El sistema calcula automáticamente el pago al diseñador en cada cotización.

Beneficio comercial: Fidelización. Venderle al mismo cliente cuesta 5x menos que conseguir uno nuevo.

Módulo 8 — Suscripción y Pagos

Gestión de planes, roles y cobros recurrentes integrados con Mercado Pago.

Explicación de ventas

Si vendes el ERP como SaaS, necesitas cobrar a tus clientes. Este módulo lo hace automático:

  • Planes configurables: Define precios por rol (vendedor $500/mes, diseñador $650/mes, admin $0/mes). Períodos de 30 días.
  • Mercado Pago: Integración para cobro automático de suscripciones.
  • Gestión de usuarios: Tabla completa con rol, horas trabajadas, vencimiento de suscripción, cobro MP y activación/desactivación.
  • Recordatorios automáticos: Correos de suscripción/pago a usuario y admin si no se desactivan en Perfiles.

Beneficio comercial: Automatiza el cobro de licencias del ERP. El admin no tiene que perseguir clientes para que paguen.

Módulo 9 — Configuración y Seguridad

Panel de control del administrador del taller.

Explicación de ventas

El dueño del taller tiene control total sin necesidad de un técnico:

  • Configuración personal: Edita nombre, correo, contraseña (mín. 12 caracteres con mayúscula, minúscula, número y símbolo). Cambios se actualizan en todos los perfiles.
  • Porcentaje para inversión: Define qué % de la ganancia neta se considera reinversión (por defecto 10%). Se aplica en Dashboard y Productos.
  • Alarmas y alertas: Programa alertas manuales o activa recordatorios automáticos de suscripción/pago vía correo SMTP del servidor.
  • Seguridad: Panel de seguridad con logs de acceso, intentos fallidos y gestión de sesiones.
  • Videos promocionales: Sube enlaces de TikTok/Instagram/YouTube y aprueba solicitudes de vendedores. Aparecen automáticamente en la landing.
  • Costos calculadora pública: Configura los precios por kg que muestra la calculadora pública de la landing sin revelar tu margen real.

Beneficio comercial: Centraliza el control. Un solo admin puede gestionar 10 vendedores sin perder el norte.

Módulo 10 — Editor Web Pública

Modifica tu landing page sin tocar código. Desde el ERP.

Explicación de ventas

No necesitas un programador para cambiar el texto de tu web:

  • Editor JSON: Modifica textos, colores, CTAs y estadísticas de la landing directamente desde el ERP. Guarda y se publica al instante.
  • Subir archivos estáticos: Sube imágenes, PDFs u otros archivos que se sirven públicamente vía nginx.
  • Editor de galería: Crea categorías y sube imágenes de proyectos para la galería pública. Sin FTP, sin Git.

Beneficio comercial: Agiliza cambios de marketing. Un nuevo producto o promoción se publica en minutos, no en días.

Módulo 11 — Análisis y Reportes

Dashboard ejecutivo. Números claros para decisiones estratégicas.

Explicación de ventas

¿Tu taller gana dinero o solo trabaja mucho? Este módulo responde:

  • Ingresos totales: Suma de todas las ventas del periodo.
  • Pedidos completados: Volumen de operación.
  • Ticket promedio: Cuánto gasta cada cliente (ideal para upselling).
  • Margen bruto %: Rentabilidad del negocio. Alerta si baja de 20%.
  • Ingresos por periodo: Gráfica de tendencia para identificar temporadas altas.
  • Productos del periodo: Tabla detallada: producto, cantidad, venta, costo, ganancia, margen % y descuento.
  • Desglose de costos: Cuánto se gastó en material, tiempo máquina, diseño, extras, empaque y envío.

Beneficio comercial: Identifica qué productos dejan más ganancia y cuáles solo generan trabajo. Ajusta precios con datos, no con corazonadas.

Ingeniería de Software & Stack

Sistemas diseñados para la alta disponibilidad, seguridad y escalabilidad empresarial.

⚛️

Frontend de Próxima Gen

React 19 + Vite 7 + Tailwind CSS v4. Arquitectura basada en componentes, renderizado optimizado y experiencia de usuario fluida en cualquier dispositivo.

🐍

Backend de Alto Rendimiento

FastAPI + SQLAlchemy async + Pydantic v2. API REST asíncrona optimizada para baja latencia y validación de datos estricta.

🗄️

Persistencia de Datos

PostgreSQL listo para producción. Modelo relacional normalizado para integridad total de la información y consultas complejas eficientes.

🐳

Infraestructura Cloud

Docker + Docker Compose en VPS Hostinger. Cloudflare Tunnel para exposición segura sin abrir puertos y Nginx como reverse proxy.

🔒

Capa de Seguridad

Implementación de MFA vía email, hashing bcrypt para contraseñas, tokens JWT de sesión y tráfico HTTPS forzado mediante SSL.

🚀

Ciclo de Despliegue

Frontend en Vercel (Edge Network) y Backend en VPS dedicado. Pipeline de deploy continuo mediante Git + Docker para actualizaciones sin downtime.

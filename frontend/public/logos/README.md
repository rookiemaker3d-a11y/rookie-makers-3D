# Logos ROOKIE MAKERS 3D

Coloca aquí las imágenes del logo con estos nombres:

- **logo-cotizacion.png** – Versión blanco y negro para el PDF de cotización.
- **logo-erp.png** – Logo para la cabecera del ERP (opcional; si no existe se usa logo-cotizacion.png).
- **logo-web.png** – Logo para la página pública (landing).

Si no existen, la app usará un placeholder o texto. Las imágenes que subiste (variantes B/N, gris y azul) pueden copiarse desde la carpeta de assets de Cursor a esta carpeta con los nombres indicados.
